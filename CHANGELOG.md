# Changelog

## [1.1.0] - Aurora Update (Release Candidate)

### Added
- PDF, DOCX and TXT document extraction.
- Drag-and-drop document upload.
- Separate upload and paste modes.
- Animated input mode selector.
- Expandable extracted text preview.
- Document validation and extraction metadata.
- Interactive contract preview.
- Automated backend tests.

### Improved
- Complete Aurora UI redesign.
- Animated document analysis loader.
- Full-width analysis results.
- Responsive layouts and hover effects.
- Modular backend architecture.
- Error handling and input management.

### Verification
- 26 backend tests passed.
- Frontend production build passed.

### Known Limitations
- Analysis limited to 50,000 characters.
- Scanned PDFs requiring OCR are unsupported.
- Production and end-to-end verification pending.

## [1.0.0] - Initial MVP

- AI-powered contract analysis.
- Contract-specific risk assessment.
- Executive summaries and key facts.
- Clause explanations.
- Gemini model fallback.
